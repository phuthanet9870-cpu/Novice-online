# Novice Online — Game Concept (v0.1)

> MMORPG แนว 2.5D มุมมองไอโซเมตริก เล่นบนเว็บด้วย HTML5 (ไม่ต้องติดตั้ง)
> แก่นของเกม: **PvP / Guild War / Boss & World Boss / ฟาร์มของ / ตีบวก +20 / เลเวล 250 / คอมโบสกิล**

---

## 0. เสาหลักของเกม (Design Pillars)

| เสาหลัก | ความหมาย |
|---|---|
| **Combo First** | สกิลทุกตัวมี "แท็กสถานะ" ที่ส่งต่อให้สกิลถัดไป การกดสกิลถูกลำดับ = ดาเมจคูณหลายเท่า |
| **Build Freedom** | 50 สกิล/คลาส แต่แต้มสกิลไม่พอเก็บครบ ต้องเลือกสาย → 1 คลาสมีหลายบิลด์ |
| **Grind ที่มีความหมาย** | ฟาร์มรูน ประดับ วัตถุดิบตีบวก ทุกอย่างซื้อขายได้ |
| **Social Conflict** | กิลด์แย่งปราสาท, World Boss แย่งอันดับดาเมจ, Ranked PvP |
| **Respect Time** | มีระบบ Auto (เฉพาะ PvE) ที่ตั้งค่าละเอียดได้ ผู้เล่นงานยุ่งก็ยังโตได้ |

### 1.2 สเตตัส (Stat)
| Stat | ผล |
|---|---|
| STR | ATK กายภาพ, น้ำหนักแบก |
| AGI | ความเร็วโจมตี (ASPD), Flee |
| VIT | HP สูงสุด, ลดดาเมจกายภาพ, ต้านสถานะ |
| INT | MATK, SP สูงสุด, ลดดาเมจเวท |
| DEX | Hit, ความเร็วร่าย (Cast), ดาเมจระยะไกล |
| LUK | คริติคอล, ดรอปเรต(เล็กน้อย), Perfect Dodge |

- ได้ **5 แต้มสเตตัส / เลเวล** (+ โบนัสทุก 10 เลเวล)
- สเตตัสสูงสุด 300 ต่อสาย (ไม่รวมบัฟ/อุปกรณ์)

### 1.3 เลเวล 1 – 250
| ช่วงเลเวล | ช่วงเกม | ปลดล็อก |
|---|---|---|
| 1–50 | Early | สกิลพื้นฐาน, เควสหลัก, ดันเจี้ยน 1 |
| 51–100 | Mid | **Awaken I** (ปลด Ultimate 1–2), เข้ากิลด์วอร์ได้, ตีบวก +11 ขึ้นไป |
| 101–150 | Late | Rune Slot ช่องที่ 3, World Boss |
| 151–200 | End | **Awaken II** (ปลด Ultimate 3–4) |
| 201–250 | Endgame | **Awaken III** (Ultimate 5), Abyss Dungeon, Mythic Gear |

- EXP curve แบบเอกซ์โพเนนเชียล: เลเวล 200 → 250 ใช้เวลาเท่ากับ 1 → 200
- ตายเสีย EXP 1% (เฉพาะ PvE, PvP/GvG ไม่เสีย)

## 2. ระบบสกิลและบิลด์

### 2.1 โครงสร้าง 50 สกิล / คลาส
| ประเภท | จำนวน | หมายเหตุ |
|---|---|---|
| สกิลโจมตี (Attack) | 40 | แบ่งเป็น 3 สาย สายละ ~13 สกิล + พื้นฐาน |
| อัลติเมต (Ultimate) | 5 | ใช้ **Rage/Focus Gauge** 100% ไม่ใช้ SP, ปลดตาม Awaken |
| บัฟ (Buff) | 5 | บัฟตัวเอง/ปาร์ตี้ ติดตัวได้พร้อมกันสูงสุด 3 |

### 2.1.1 ระบบสกิล v3 — แยกหมวด Active / Ultimate / Buff และไม่ซ้ำกันทั้งเกม
- ตำราสกิลแยก 3 แท็บ: **Active 40 · Ultimate 5 · Buff 5** ต่อคลาส
- **Active** ออกแบบใหม่ทั้งหมดจาก "ชุดอุปกรณ์" ของแต่ละคลาส (`tools/skill-design.js`): รูปแบบการโจมตี × สถานะประจำคลาส × กลไกคอมโบ (Finisher ใช้สถานะ, ระเบิดชั้นสถานะ, ใช้พลังพิเศษ, ต่อจากสกิลก่อนหน้า, ปิดฉาก, แทงข้างหลัง ...) × ความสามารถเสริม (ดูดเลือด, โล่, ผลัก, ล่องหน ...) — ไม่มีชุดผสมซ้ำกันทั้งเกม ชื่อสกิลสร้างจากกลไกจริง และคำอธิบายสร้างจากค่าจริง
- **Ultimate / Buff** ออกแบบเฉพาะคลาสด้วยมือ (แปลงร่าง, หลุมดำ, ชุบชีวิต, กองทัพผี, ดาวเทียม ...)
- ทุกสกิลมี ✦ คุณสมบัติเฉพาะ, เอฟเฟกต์ภาพ, ไอคอน (กรอบตามหมวด) และเสียงที่ไม่ซ้ำ · ตัวคอมไพล์ตรวจความไม่ซ้ำทุกด้าน · รายการเต็มใน [SKILLS_CATALOG.md](SKILLS_CATALOG.md)

### 2.1.2 ค่าสเตตัสแบบ ARPG + Passive Tree 1000 โหนด
- ไม่มีแต้มสเตตัส: STR/AGI/VIT/INT/DEX/LUK เพิ่มอัตโนมัติทุกเลเวลตามคลาส (สเตตัสหลักโตเร็วสุด)
- **Passive Skill Tree 1000 โหนด** แบบ PoE2: 14 วง ทุกคลาสเริ่มคนละจุด · โหนดย่อย 833 · Notable 137 (ชื่อเฉพาะ หลายโบนัส) · Keystone 20 (ข้อแลกเปลี่ยนใหญ่ เช่น Glass Cannon +40% ดาเมจ −30% HP) · ได้ 1 แต้มต่อเลเวล + โบนัสทุก 10 เลเวล (274 แต้มที่ Lv250) · คลิกโหนดไกล = เลือกทั้งเส้นทาง · คืนแต้มทีละโหนดได้

### 2.2 แต้มสกิล
- ได้ 1 แต้ม/เลเวล + 50 แต้มจากเควส = **300 แต้ม** ที่เลเวล 250
- สกิลโจมตีอัปได้ Lv 1–10, บัฟ Lv 1–10, Ultimate Lv 1–5
- อัปครบทุกสกิล = 40×10 + 5×10 + 5×5 = **475 แต้ม** → เก็บได้แค่ ~63% → **บังคับให้เลือกบิลด์**
- Skill Lv 5 และ Lv 10 ปลด **"Skill Mod"** (เลือก 1 ใน 2 ผลเสริม) เช่น "เพิ่มระยะ" หรือ "เพิ่มสถานะเลือดออก"

### 2.3 Hotbar & Loadout
- ติดตั้งสกิล Active ได้ 12 ช่อง + Ultimate 2 ช่อง + Buff 3 ช่อง
- บันทึก **Build Preset** ได้ 3 ชุด (PvE / PvP / GvG) สลับได้ในเมือง
- รีเซ็ตสกิล: ฟรีจนถึง Lv 100, หลังจากนั้นใช้ไอเทม "Memory Crystal"

## 3. ระบบคอมโบ (หัวใจของเกม)

### 3.1 แท็กสถานะ (Combo States)
สกิลทุกตัว **ใส่** หรือ **ใช้ (Consume)** แท็กสถานะ

| แท็ก | ไอคอน | ผลพื้นฐาน | ระยะเวลา |
|---|---|---|---|
| **Airborne** ลอยกลางอากาศ | ⬆ | ขยับ/ใช้สกิลไม่ได้ | 1.5s |
| **Knockdown** ล้มลง | ⬇ | ขยับไม่ได้, รับดาเมจ +10% | 2s |
| **Stun** มึน | 💫 | ทำอะไรไม่ได้ | 1.5s |
| **Bleed** เลือดออก | 🩸 | DoT กายภาพ, ซ้อน 5 ชั้น | 6s |
| **Poison** พิษ | ☠ | DoT, ลดฮีลที่ได้รับ 30% | 8s |
| **Burn** ติดไฟ | 🔥 | DoT ไฟ, ซ้อน 3 ชั้น | 5s |
| **Freeze / Chill** หนาว/แช่แข็ง | ❄ | Chill ซ้อน 3 ชั้น = Freeze | 3s |
| **Wet** เปียก | 💧 | ต้านไฟ +, รับดาเมจสายฟ้า +50% | 6s |
| **Shock** ช็อต | ⚡ | ขัดการร่าย | 2s |
| **Mark** ตราประทับ | 🎯 | เป้าหมายถูกล็อก, ใช้กับสกิล Finisher | 8s |
| **Armor Break** เกราะแตก | 🛡✖ | DEF -30% | 6s |
| **Curse** คำสาป | 👁 | LUK=0, ลด ATK 20% | 10s |
| **Slow / Root** ชะลอ/ตรึง | 🐌 | ลดความเร็ว / ขยับไม่ได้ | 3s |
| **Holy Brand** ตราศักดิ์สิทธิ์ | ✝ | ดาเมจ Holy ที่ได้รับ +25% | 8s |

### 3.2 บทบาทของสกิลในคอมโบ
- **Starter (S)** – เปิดคอมโบ ใส่แท็ก
- **Linker (L)** – ได้โบนัสถ้าเป้ามีแท็ก และส่งต่อแท็กใหม่
- **Finisher (F)** – **ใช้แท็กทิ้ง** แลกกับดาเมจมหาศาล/ผลพิเศษ

ตัวอย่าง (Blade Knight):
```
Rising Slash (S: Airborne) → Sky Pierce (L: ต่อเป้าลอย +50%, ใส่ Bleed)
→ Meteor Drop (F: ใช้ Airborne → Knockdown + 300%) → Execution Edge (F: ใช้ Bleed ทุกชั้น)
```

### 3.3 Combo Counter & Combo Gauge
- ทุกครั้งที่สกิลถัดไปลงภายใน **Combo Window 2.5 วินาที** → Combo +1
- โบนัสดาเมจ: +3% ต่อ Combo (สูงสุด +60% ที่ 20 Combo)
- Combo ที่ 5/10/15/20 ชาร์จ **Ultimate Gauge** เพิ่ม 10/15/20/30%
- สกิลซ้ำตัวเดิมติดกันไม่นับคอมโบ (บังคับให้หมุนสกิล)

### 3.4 Element Reaction (ข้ามคลาสได้)
| แท็ก A + สกิลธาตุ B | ปฏิกิริยา | ผล |
|---|---|---|
| Wet + Lightning | **Electrocute** | ดาเมจ ×2, Stun 1.5s, กระโดดไป 3 เป้า |
| Burn + Wind | **Firestorm** | ไฟลามเป็นวง AoE |
| Chill/Freeze + กายภาพหนัก | **Shatter** | ดาเมจ ×2.5 ทะลุ DEF |
| Burn + Freeze | **Steam Burst** | AoE ระเบิด, ล้างทั้งสองแท็ก |
| Poison + Fire | **Toxic Blaze** | ควันพิษกระจาย AoE |
| Curse + Holy | **Purge** | ดาเมจ Holy ×3 ต่อเป้าที่ถูกสาป |
| Holy Brand + Dark | **Twilight** | ดาเมจจริง (True Damage) 15% HP สูงสุด (Boss 3%) |
| Armor Break + Bleed | **Hemorrhage** | Bleed ทำงานเร็วขึ้น 2 เท่า |

> ปาร์ตี้ที่ประสานกันได้ (เช่น Elementalist ใส่ Wet → Gunslinger ยิงกระสุนสายฟ้า) จะได้เปรียบมากใน Boss/GvG

### 3.5 กฎ PvP สำหรับคอมโบ (กันโดนจับวนตาย)
- **CC Diminishing Returns**: CC ชนิดเดียวกันโดนครั้งที่ 2 = 50%, ครั้งที่ 3 = 25%, แล้วภูมิคุ้มกัน 8s
- **Break Free**: ทุกคลาสมีปุ่ม "หลุดสถานะ" CD 25s (ใช้ Stamina)
- Combo damage bonus ใน PvP ลดเหลือครึ่งหนึ่ง

## 4. ไอเทม / ตีบวก / รูน / ประดับ

### 4.1 ช่องอุปกรณ์
อาวุธ, มือรอง/โล่, หมวก, หน้ากาก, เกราะ, ผ้าคลุม, รองเท้า, **ประดับ ×4** (สร้อยคอ, ต่างหู, แหวน ×2), **Relic** ×1

### 4.2 ระดับความหายาก
`Common (ขาว) → Uncommon (เขียว) → Rare (ฟ้า) → Epic (ม่วง) → Legendary (ส้ม) → Mythic (แดง)`

- ของ Rare ขึ้นไปมีออปชั่นสุ่ม (Random Options) 1–4 บรรทัด ล้างออปชั่นได้ด้วย "Reroll Stone"

### 4.3 ตีบวก +0 → +20
| ระดับ | อัตราสำเร็จ | ล้มเหลว | วัตถุดิบ |
|---|---|---|---|
| +1 ~ +6 | 100% → 80% | ไม่มีผล | Refine Ore |
| +7 ~ +10 | 70% → 45% | ลด -1 | Refine Ore + Zeny |
| +11 ~ +15 | 40% → 15% | ลด -1 ถึง -3 | Pure Refine Crystal |
| +16 ~ +20 | 12% → 2% | **พัง (ของหายกลายเป็นเศษ)** หรือ -3 | Divine Crystal |

- **Protection Scroll** ป้องกันพัง (ยังลดระดับได้), **Blessed Scroll** ป้องกันลดระดับ
- **Pity System**: ล้มเหลวสะสม → เพิ่มโอกาส +0.5%/ครั้ง (รีเซ็ตเมื่อสำเร็จ)
- โบนัสตีบวก: อาวุธ +ATK/MATK % ต่อระดับ, +10/+15/+20 ปลด **เอฟเฟกต์แสง** และโบนัสพิเศษ
- ประกาศทั้งเซิร์ฟเมื่อมีคนตี +18 ขึ้นไปสำเร็จ

### 4.4 รูน (Rune)
- อุปกรณ์มีช่องรูน 0–3 ช่อง (เจาะเพิ่มได้ด้วย "Rune Drill")
- รูนดรอปจากมอนสเตอร์/บอส (แบบการ์ด แต่เป็นรูนของเกมเอง)
- รูนมี 4 ประเภท: **Offense / Defense / Utility / Skill Rune** (Skill Rune เปลี่ยนพฤติกรรมสกิล เช่น "Rising Slash ลอยนานขึ้น 0.5s")
- **Rune Set**: ใส่ 3 ชิ้นธีมเดียวกัน = โบนัสเซ็ต
- รวมรูนซ้ำ 3 อัน → อัปเกรด Tier (I → V)
- รูนบอส (Boss Rune) มีเอฟเฟกต์เฉพาะ ดรอปต่ำมาก

### 4.5 ประดับ (Accessories & Jewels)
- ประดับ 4 ช่อง (สร้อย, ต่างหู, แหวน ×2) มีเซ็ตโบนัส
- **Jewel / อัญมณีประดับ**: ฝังในประดับเท่านั้น (Ruby=ATK, Sapphire=MATK, Emerald=HP, Topaz=Crit ...)
- อัญมณีรวม 5 → 1 ระดับสูงขึ้น (สูงสุด Lv 10)
- ประดับตีบวกได้ถึง +10 (ตารางแยก)

### 4.6 การฟาร์ม
| แหล่ง | ได้อะไร |
|---|---|
| มอนสเตอร์ทั่วไป | วัตถุดิบ, Refine Ore, รูน Tier I |
| Elite (มอนเรืองแสง) | รูน Tier II, Jewel |
| ดันเจี้ยนปาร์ตี้ (รีเซ็ตรายวัน) | ชุดเซ็ต, Pure Crystal |
| Field Boss / MVP | รูนบอส, ของ Epic+ |
| World Boss | Legendary/Mythic, Divine Crystal |
| Abyss Tower (100 ชั้น, ลงคนเดียว) | Skill Rune, ไอเทมรีเซ็ต |

- ระบบ **Loot Rights**: ดรอปเป็นของคนที่ทำดาเมจมากสุด/ปาร์ตี้นั้น 30 วินาทีแรก
- ตลาด: ร้านค้าผู้เล่น (Vending) + Auction House + เทรดตรง

## 5. Boss & World Boss

### 5.1 Field Boss (MVP)
- เกิดตามเวลาสุ่มในช่วง (เช่น 60–90 นาที) ในแผนที่ประจำ
- ได้ **MVP** = ผู้ทำดาเมจสูงสุด ได้กล่องรางวัลพิเศษ + EXP โบนัส
- บอสมี **Phase** (HP 70% / 40% / 10%) เปลี่ยนท่า เรียกลูกน้อง
- บอสมี **Stagger Gauge**: โจมตีด้วยสกิล Finisher หรือ Reaction ลดเกจ เมื่อหมด → บอสล้ม 5 วิ รับดาเมจ ×2 (คอมโบสำคัญมากกับบอส)

### 5.2 World Boss
- เกิด 3 รอบ/วัน ตามตารางเวลา (เช่น 12:00 / 19:00 / 22:00) ประกาศก่อน 10 นาที
- HP ปรับตามจำนวนผู้เล่นในแผนที่
- **โซน PvP เปิดอัตโนมัติ** ระหว่างตีบอส (แย่งกันได้ กิลด์ต้องคุ้มกันสมาชิก)
- รางวัลตาม **อันดับดาเมจ**: Top 1 / Top 10 / Top 50 / ผู้เข้าร่วม
- รางวัลกิลด์: กิลด์ที่ทำดาเมจรวมสูงสุดได้ Guild Coin + บัฟทั้งกิลด์ 24 ชม.
- กลไกพิเศษ: บอสชี้เป้าผู้เล่น, พื้นที่อันตราย, ต้องใช้ Reaction ทำลายเกราะธาตุ

### 7.2 Guild War (Siege)

- **Alliance**: เป็นพันธมิตรได้ 2 กิลด์
- **Guild Match (GvG Arena)** 20v20 วันพุธ แบบจัดคู่ตาม Rating

## 8. ระบบ Auto (ออโต้)

> เปิดใช้ได้เฉพาะแผนที่ PvE ปิดอัตโนมัติใน PvP/GvG/World Boss (ตั้งค่าได้ที่ GM)
> **Auto ทำงานฝั่ง Server** (server-side AI controller) → ปิดเบราว์เซอร์แล้วยังฟาร์มต่อได้ (Offline Auto) ตามเวลา "Auto Ticket"

### 8.1 ตั้งค่าการตีมอน (Target Settings)
- **โหมดเลือกเป้า**: ใกล้สุด / HP น้อยสุด / ตามลำดับความสำคัญ / ตีคืนเฉพาะที่ตีเรา
- **รายการมอนที่ต้องการตี** (Whitelist) พร้อมลำดับความสำคัญ 1–5
- **รายการมอนที่ไม่ตี** (Blacklist) และ "หนีเมื่อเจอ" (Avoid list เช่นบอส)
- รัศมีการค้นหา (5–30 ช่อง) / ยึดจุดศูนย์กลาง (Anchor point) ไม่เดินออกนอกวง
- ไม่แย่งมอนที่คนอื่นตีอยู่ (KS Protection)

### 8.2 ตั้งค่าลำดับสกิล (Skill Rotation)
- ลากสกิลเรียงลำดับได้ 12 ช่อง + กำหนด **เงื่อนไข** ต่อสกิล:
  - `ถ้าเป้ามีแท็ก [Airborne]` → ใช้สกิลนี้
  - `ถ้า HP เป้า < 30%` / `ถ้า SP ตัวเอง > 50%` / `ถ้ามอนรอบตัว ≥ 3`
  - `ใช้เป็น Opener` / `ใช้เมื่อ Combo ≥ 5`
- **Combo Preset**: บันทึกชุดคอมโบสำเร็จรูป (เช่น S→L→F) ให้ออโต้กดเป็นชุด
- ใช้ Ultimate อัตโนมัติ (เปิด/ปิด, เฉพาะ Elite/Boss)
- รักษาบัฟอัตโนมัติ (ต่อบัฟเมื่อเหลือ < X วินาที)

### 8.3 ตั้งค่าการเอาตัวรอดและอื่นๆ
- ใช้ยา HP/SP เมื่อต่ำกว่า X%, ใช้ยาฉุกเฉิน, ใช้ Break Free เมื่อโดน CC
- กลับเมืองเมื่อ: ยาหมด / กระเป๋าเต็ม / น้ำหนักเกิน / ตาย
- ซื้อยาอัตโนมัติ + ขายขยะ + กลับมาจุดเดิม (Auto Supply)
- **Loot Filter**: เก็บตามความหายาก / ตามชื่อ / ไม่เก็บขยะ
- Party Auto: Healer ฮีลเพื่อนเมื่อ HP < X%, Tank ยั่วมอน
- **Auto Report**: สรุปผลหลังจบ (EXP/ชม., ไอเทมที่ได้, ตายกี่ครั้ง)

### 8.4 ป้องกันการบอท
- ออโต้ทางการฟรี → ไม่มีเหตุให้ใช้บอทนอก
- ตรวจจับ input ผิดปกติ, Rate limit แพ็กเก็ต, ทุกอย่างคำนวณฝั่ง Server

## 9. ระบบ GM (คำสั่ง GM ควบคุมได้ทุกอย่าง)

### 9.1 ระดับสิทธิ์
| Level | ตำแหน่ง | สิทธิ์ |
|---|---|---|
| 1 | Helper | ดูข้อมูล, ประกาศ, warp ตัวเอง |

## 10. สถาปัตยกรรมเทคนิค (HTML5 Online)

```
┌───────────── Browser (HTML5) ─────────────┐
│  TypeScript + PixiJS (render 2.5D)        │
│  UI: HTML/CSS overlay (Hotbar, Inventory) │
│  Client prediction (เดินเท่านั้น)           │
└───────────────┬───────────────────────────┘
                │ WebSocket (binary msgpack) / HTTPS (login, REST)
┌───────────────▼───────────────────────────┐
│ Gateway / Auth (JWT)                      │
├───────────────────────────────────────────┤
│ Game Server (Node.js + TypeScript)        │
│  - 1 Map = 1 Room, Tick 20Hz              │
│  - Server authoritative: ดาเมจ/ดรอป/ตีบวก   │
│  - Skill engine อ่าน data JSON            │
│  - Auto AI controller (server-side)       │
│  - GM command module + permission         │
├───────────────────────────────────────────┤
│ Redis: session, ตำแหน่ง, pub/sub ข้ามแมพ   │
│ PostgreSQL: บัญชี ตัวละคร ไอเทม กิลด์ log   │
│ GM Web Panel (Admin)                      │
└───────────────────────────────────────────┘
```

- **Data-driven**: สกิล/มอน/ไอเทม/ดรอป เก็บเป็น JSON → แก้ได้โดย `@reload`
- ทุกการกระทำสำคัญ (ตีบวก, เทรด, ดรอป Legendary) ทำแบบ transaction + log
- รองรับมือถือ (Touch controls + Auto) และ PC (คีย์ลัด 1–0, Q-E, F1-F4)
