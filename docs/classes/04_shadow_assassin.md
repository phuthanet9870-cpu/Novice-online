## คอมโบแนะนำ
- **Assassin One-Shot**: Vanish → Shadow Mark → Ambush → Phantom Blades → Assassinate
- **Venom Rot**: Acid Splash → Venom Strike → Toxic Fang → Viper Dance → Death Bloom → Final Dose
- **Storm**: Cyclone Cut → Twin Fang → Hundred Cuts → Falling Shadow
- **Party (กับ Elementalist ไฟ)**: Poison + Fire → **Toxic Blaze**
