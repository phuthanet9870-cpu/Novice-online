## คอมโบแนะนำ
- **Storm Chain**: Rain Call → Water Ball → Thunderclap → Chain Lightning → Lightning Storm
- **Freeze Shatter**: Frost Nova → Ice Shard → Frozen Lance → Glacial Prison → Frost Bloom
- **Steam**: Flame Wave → Ignite → [Freeze] → Magma Burst
- **Fusion**: Fire Bolt → Lightning Bolt → Wind Blade → Plasma
