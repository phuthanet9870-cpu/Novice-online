# 7. Cleric (นักบวช)
อาวุธ: กระบอง / คัมภีร์ · Stat หลัก: INT / VIT / DEX · ทรัพยากรพิเศษ: **Faith** (ได้จากการฮีล/ตี Holy, ใช้เสริมสกิล)

> คลาสฮีลก็มีสกิลโจมตี 40 สกิล — สกิลโจมตีหลายตัว **ฮีลไปด้วย** เพื่อให้เล่นสายตีได้และไม่น่าเบื่อ

**สายบิลด์**
- **Divine** — Holy DPS ตีแรง ใส่ Holy Brand
- **Sanctuary** — ฮีล/โล่ผ่านการโจมตี (Battle Healer)
- **Inquisitor** — กระบองประชิด ตีคนสาป ทำลายบัฟศัตรู

## คอมโบแนะนำ
- **Holy Burst**: Smite → Holy Nova → Judgment → Heaven's Hammer
- **Inquisitor Solo**: Heretic's Mark → Crusader Bash → Penance → Purge → Inquisition
- **Battle Heal**: Grace Wave → Mending Strike → Prayer Echo → Blessing Burst
- **Party (กับ Warlock)**: [Dark เพื่อน] + Holy Brand → Twilight Ray
