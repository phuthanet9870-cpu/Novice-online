# 8. Monk (นักพรตหมัด)
อาวุธ: สนับมือ / กำปั้น · Stat หลัก: STR / AGI / DEX · ทรัพยากรพิเศษ: **Chi Sphere** (สูงสุด 5 ลูก ได้จากคอมโบ, ใช้ปลดท่าไม้ตาย)

> คลาสคอมโบที่สุด: สกิลหลายตัวกดได้ **เฉพาะเมื่อสกิลก่อนหน้าเป็นสกิลที่กำหนด** (Chain Skill) และไม่มี CD ในสายนั้น

**สายบิลด์**
- **Iron Fist** — โซ่คอมโบหมัด (Chain) ยิ่งต่อยิ่งแรง
- **Tempest Kick** — เตะ ปั่นลอยฟ้า Juggling
- **Spirit Palm** — ฝ่ามือพลังชี ระยะกลาง ทะลุ DEF
