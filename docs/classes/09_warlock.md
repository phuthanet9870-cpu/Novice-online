## คอมโบแนะนำ
- **DoT Bomb**: Curse → Agony → Corruption → Malediction → Wither → Soul Rend
- **Necro Swarm**: Raise Skeleton → Bone Prison → Skeletal Charge → Command: Rend → Corpse Explosion
- **Reaper**: Soul Hook → Grim Harvest → Phantom Reap → Soul Eater → Deathblow
- **Party (กับ Cleric)**: Holy Brand + Umbral Twilight / Curse + Purge ของ Cleric
