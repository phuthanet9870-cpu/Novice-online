# 10. Gunslinger (มือปืน)
อาวุธ: ปืนพกคู่ / ไรเฟิล / ลูกซอง · Stat หลัก: DEX / AGI / LUK · ทรัพยากรพิเศษ: **Ammo + Heat** (ยิงต่อเนื่อง Heat ขึ้น ดาเมจเพิ่ม แต่ 100% = Overheat ยิงไม่ได้ 2s) และ **กระสุนพิเศษ** สลับได้ (ไฟ/น้ำแข็ง/สายฟ้า/เจาะเกราะ)

**สายบิลด์**
- **Dual Gun** — ปืนคู่ ยิงพร้อมเคลื่อนที่ สไตล์ Gun-fu ระยะใกล้

- **Demolition** — ลูกซอง ระเบิด ปืนใหญ่ AoE
